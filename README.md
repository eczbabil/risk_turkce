# RİSK — Dünya Hakimiyeti

Türkçe arayüzlü klasik Risk strateji oyunu.

## Oyunu yayınlama
Depo kök dizinindeki `index.html` ve `assets/` dosyaları hazırdır. GitHub Pages'i açmak için:
1. Depoda **Settings → Pages** bölümüne girin.
2. **Build and deployment → Deploy from a branch** seçin.
3. Branch olarak `main`, klasör olarak `/ (root)` seçip **Save**'e basın.
4. Yayınlandıktan sonra oyun adresi: https://eczbabil.github.io/risk_turkce/

## İçerik
- Klasik Risk tahtası: 42 bölge ve 6 kıta
- Saldırı, zar çözümleme, takviye ve bölge fethetme
- Kıta bonusları ve bölge kartları
- Yapay zekâ rakip
